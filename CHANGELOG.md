# Changelog / Änderungsprotokoll

## 1.1.0

**English**
- New: password generator (16 characters), with "show password" and "copy to clipboard".
- New: e-mail address field. It follows the UPN by default and can be edited or left empty. Duplicate e-mail addresses are detected.
- New: MSI package (WiX v5), with an optional desktop shortcut (`DESKTOPSHORTCUT=1`).
- New: GitHub Actions build for EXE, MSI and ZIP. A release is created automatically for tags `v*`.
- New: version number in the window title. It is used by all build scripts.
- New: documentation in English and German.

**Deutsch**
- Neu: Kennwort-Generator (16 Zeichen), mit „Kennwort anzeigen“ und „In Zwischenablage kopieren“.
- Neu: Feld für die E-Mail-Adresse. Sie folgt standardmäßig dem UPN und kann geändert oder leer gelassen werden. Doppelte E-Mail-Adressen werden erkannt.
- Neu: MSI-Paket (WiX v5), mit optionaler Desktop-Verknüpfung (`DESKTOPSHORTCUT=1`).
- Neu: Build über GitHub Actions für EXE, MSI und ZIP. Bei Tags `v*` wird automatisch ein Release erstellt.
- Neu: Versionsnummer im Fenstertitel. Sie wird von allen Build-Skripten verwendet.
- Neu: Dokumentation auf Englisch und Deutsch.

## 1.0.0

**English**
- First version: domain controller selection, template search, UPN generation with selectable suffix, copying of group memberships and attributes, EXE build (PS2EXE) and Install.ps1.

**Deutsch**
- Erste Version: Auswahl des Domain Controllers, Vorlagensuche, UPN-Erzeugung mit auswählbarem Suffix, Übernahme von Gruppenmitgliedschaften und Attributen, EXE-Build (PS2EXE) und Install.ps1.
